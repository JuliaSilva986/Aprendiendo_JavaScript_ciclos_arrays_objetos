# Aprendiendo JavaScript: Ciclos, Arrays y Objetos 🍎

Este repositorio contiene ejercicios prácticos que realicé durante mi aprendizaje de JavaScript, enfocándome en el uso de ciclos, arrays y objetos.

## 📚 Temas practicados

1. Ciclos `for` y `while`

2. Arrays

3. Funciones flecha

4. Objetos

## 🍓 Proyecto: Clasificación de frutas

El proyecto consiste en clasificar y contar diferentes tipos de frutas almacenadas en un array de 40 elementos.

Se practicaron dos formas de resolver el problema:

1. **Usando `filter()` y `length`:** para contar cuántas veces aparece cada fruta.
2. **Usando un ciclo `while`:** para recorrer el array y actualizar los contadores mediante condicionales.

El resultado se muestra en la consola del navegador.
